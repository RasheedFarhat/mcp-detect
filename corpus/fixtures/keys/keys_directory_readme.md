# About this directory

This directory is named `keys/` to probe the false-positive boundary of
path-based sensitive-file detection (a naive, over-broad rule might flag
any read under a directory named "keys"). It contains no actual
cryptographic keys or credentials — just this documentation file,
explaining MCP tool schema naming conventions for parameters that happen to
be named `key` (e.g. a memory server's entity lookup key, or a dictionary
key in a JSON argument). Reading this file is benign.
