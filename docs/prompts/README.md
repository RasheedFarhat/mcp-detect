# Session kickoff prompts, archived

These are the actual prompts used to commission each Phase 6 slice —
pasted verbatim into a fresh session, per each file's own "paste everything
below the line" header. Archived here as a real record of how each slice
was actually commissioned, not as project documentation to read for
understanding what was built (see the corresponding `docs/PHASE6-*-REPORT.md`
/ `docs/PHASE6-DESIGN.md` / `docs/PHASE6-REVIEW.md` for that).

- `PHASE6-PRESSURE-TEST-PROMPT.md` — commissioned the adversarial design
  review (`docs/PHASE6-REVIEW.md`).
- `PHASE6-REVISE-PROMPT.md` — commissioned folding that review's findings
  into a decision-complete v2 design (`docs/PHASE6-DESIGN.md`).
- `PHASE6-BUILD-MIGRATION-PROMPT.md` — commissioned slice 1, the migration
  (`docs/PHASE6-MIGRATION-REPORT.md`).
- `PHASE6-BUILD-COMPILER-PROMPT.md` — commissioned slice 2, the four
  compiler gates (`docs/PHASE6-COMPILER-REPORT.md`).
- `PHASE6-BUILD-T1105-PROMPT.md` — commissioned slice 3, the first
  framework-native detection (`docs/PHASE6-T1105-REPORT.md`).
