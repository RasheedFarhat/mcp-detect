# Synthetic worked examples

Everything in this directory is fabricated for reproducible research. It is
not customer work and contains no production traffic.

| Example | Purpose |
|---|---|
| [`northwindpay/`](northwindpay/) | Fictional multi-server telemetry environment with sealed ground truth and generated reports |
| [`reference-mcp-review/`](reference-mcp-review/) | Cross-tenant authorization defect, exact source fix, evidence manifest, and denied retest |

The canonical rules, corpora, and framework remain in the repository root;
these examples demonstrate how those components behave together.
